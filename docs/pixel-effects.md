# 강호행 도트 요청서: 이펙트와 무기

공격 이펙트, 발사체, 입자, 초식 전용 이펙트, 무기, 아이콘을 ChatGPT에 맡기는 문서야. 번호는 E로 시작해.

## 먼저 읽을 것

- 이펙트는 프레임이 이어지는 연속 동작이 ChatGPT의 약점이야. 프레임이 안 이어지면 프레임 수를 줄여서 쓸게.
- 프레임을 가로 한 줄로 받아서 내가 잘라 넣어. 프레임 사이를 띄워 달라고 해야 잘 잘려.
- 이펙트는 인물 위에 겹쳐 그려. 그래서 배경이 깨끗해야 해.

**순서**

1. 아래 "시험"부터 뽑아서 나한테 보내 줘. 이게 게임에 잘 들어가는지 먼저 확인해야 나머지가 헛일이 안 돼.
2. 시험을 통과하면 위에서부터 차례로 뽑아. 번호를 같이 적어 보내 주면 내가 번호로 찾아 넣을게.
3. 이 문서 하나는 대화방 하나에서 뽑아. 대화방이 바뀌면 화풍이 달라져. 다른 문서는 다른 대화방에서 해도 돼.
4. 그림이 마음에 안 들면 그 번호만 다시 뽑으면 돼. 파일 이름은 신경 쓰지 않아도 돼.

**대화방 첫 줄에 붙일 문장**

```
앞으로 그리는 그림은 전부 같은 게임에 들어가. 중국 무협 배경의 탑다운 RPG이고, 슈퍼패미컴 말기나 플레이스테이션 초기 2D 게임처럼 정갈한 도트 그림이야. 시점은 위에서 45도로 내려다본 3/4 시점. 외곽선은 어두운 색 1도트. 안티앨리어싱, 블러, 그라데이션, 반투명은 쓰지 마. 한 장에 32색 안쪽으로 그려. 글자, 워터마크, 테두리, 바닥 그림자는 넣지 마. 배경은 완전한 단색 마젠타(#FF00FF)로 칠하고, 마젠타는 그림 안에 쓰지 마. 일본 사무라이나 서양 판타지가 아니라 명나라 복식과 건축을 따라.
```
