# 대사 작성 기준

글을 쓰거나 고칠 때 이 문서를 먼저 봅니다.

## 피할 것

- 대화 끝마다 나오는 명언이나 한 줄 농담. 예: “이긴 놈이 장부를 쓰는 거다”, “쌀은 쌀이죠”
- 모든 인물이 똑같이 건조하게 받아치는 말투
- 밥값, 방값, 외상, 장부, 값 같은 소재를 아무 데나 다시 쓰기. 곽 아주머니 장면에서만 씁니다
- “A가 아니라 B다”, 세 개씩 늘어놓기, 앞뒤를 맞춘 대구
- 시처럼 짧게 끊어 줄을 바꾸는 내레이션
- 여운을 남기려고 덧붙인 마지막 문장
- 말줄임표 남용
- 다 알면서 돌려 말하는 대사. 궁금하면 묻고, 아는 건 그냥 말합니다

## 쓸 것

- 사람은 할 말을 그냥 합니다. 재미없는 대사가 섞여도 됩니다
- 문장 길이를 섞습니다. 말을 고치고, 끊고, 되묻습니다
- 내레이션은 평범한 산문으로 씁니다. 있었던 일을 차례대로 적습니다
- 인물마다 말투가 달라야 이름을 가려도 누군지 알 수 있습니다
- 입말을 씁니다. 주어를 빼고, “~거든, ~잖아, ~는데, ~던데, ~나 봐”로 잇습니다
- 관용구를 씁니다. 예: 눈에 뵈는 게 없다, 입에 풀칠하다, 온데간데없다
- 내레이션은 “~했다. ~했다.”만 잇지 않습니다. “~나서야, ~는커녕, ~길래”로 흐름을 만듭니다
- “그쪽”으로 부르지 않습니다. 이름을 부르거나 주어를 뺍니다
- 읽어 봐서 실제로 이렇게 말하지 않으면 고칩니다

## 이름과 조사

- 주인공 이름은 플레이어가 정합니다. `{나}야`와 `{나}구나`는 받침에 맞춰 자동으로 바뀌고, 다른 조사를 `{나}` 바로 뒤에 붙이지 않습니다.
- 코드에서 이름 뒤 조사는 `(을)를`처럼 쓰지 말고 `josa(이름, '을/를')`을 씁니다.
- 처음 만난 사이가 아니면 처음 만난 듯한 대사를 쓰지 않습니다. 등장 순서를 확인합니다.

## 인물별 말투

| 인물 | 말투 |
|---|---|
| 주인공 | 무뚝뚝한 해요체. “네, 아니요, 그런가요”처럼 짧게 답합니다. 장문인이나 맹주 앞에서만 “~습니다”. 혼잣말과 적에게는 반말 |
| 곽 아주머니 | 시장통 아주머니. 반말, 잔소리가 길고 “아이고”, “이놈아”를 씁니다 |
| 백 노인 | “~느냐, ~구나, 이놈아”. 어른이 아이를 대하는 말투 |
| 윤설 | 해요체. 실용적이고 몸 상태부터 따집니다 |
| 소연하 | 반말. 털털하고 시비를 잘 겁니다 |
| 철우 | “소승, 시주”, 하오체. 말이 많고 먹는 얘기를 합니다 |
| 문파 어른, 혜각 | 하오체 “~하오, ~시오” |
| 맹주 연경추, 촌장 | 하게체 “자네, ~일세, ~하게” |
| 사마웅, 맹호, 산적 | 거친 반말 |
| 뱃사공 노씨 | 충청도 말투 “~여, ~구먼, ~겄네” |
| 백랑 | 능청스러운 해요체 “~거든요, ~라니까요” |
| 혁련하 | 격식체 “~습니다”. 감정을 잘 드러내지 않습니다 |
| 당소연 | 해요체. 비꼬기를 좋아합니다 |
| 남궁진 | 반말과 “~다”. 뻣뻣합니다 |
| 모용설 | 하오체에 가까운 격식 말투. 새침합니다 |
