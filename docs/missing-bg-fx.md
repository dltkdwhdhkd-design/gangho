# 강호행: 못 받은 그림 (배경·이펙트)

배경과 이펙트 쪽에서 아직 못 받은 것만 모았어. 인물과 이벤트 장면은 [missing-chars-scenes.md](missing-chars-scenes.md)에 따로 있어. 번호는 원래 요청서 다음 번호부터 이어 붙였어.

배경·이펙트를 뽑던 대화방에서 이어서 하면 돼. 새 대화방이면 이 문장부터 붙여.

```text
앞으로 그리는 그림은 전부 같은 게임에 들어가. 중국 무협 배경의 탑다운 RPG이고, 슈퍼패미컴 말기나 플레이스테이션 초기 2D 게임처럼 정갈한 도트 그림이야. 시점은 위에서 45도로 내려다본 3/4 시점. 외곽선은 어두운 색 1도트. 안티앨리어싱, 블러, 그라데이션, 반투명은 쓰지 마. 한 장에 32색 안쪽으로 그려. 글자, 워터마크, 테두리, 바닥 그림자는 넣지 마. 배경은 완전한 단색 마젠타(#FF00FF)로 칠하고, 마젠타는 그림 안에 쓰지 마. 일본 사무라이나 서양 판타지가 아니라 명나라 복식과 건축을 따라.
```

## 전투 배경

가로세로 8대 5. 마젠타 배경은 쓰지 말고 화면 끝까지 꽉 채워.

**B100. 전투 배경 dock** `arena/dock`

```text
도트 전투 배경 한 장. 가로세로 8대 5. 강나루의 넓은 나무 선착장. 판자 바닥이 화면 대부분이고, 맨 위에 강물과 매어 둔 나룻배. 인물과 글자는 그리지 마. 바닥이 화면의 85%를 차지하고 평평하게 보여야 해. 마젠타 배경은 쓰지 마.
```

## 아이콘

**E136. 아이콘 금창약** `icon/hp`

```text
도트 아이템 아이콘 하나를 정사각형으로 그려. 물건: 금창약. 상처에 바르는 가루약. 붉은 천으로 입구를 막은 작은 흰 도자기 약병. 물건 하나만 가운데에 크게, 글자는 넣지 마.
```

## 받았지만 아직 안 쓴 것

- 지도 배치도 B51~B94: 이걸 보고 맵을 다시 짜는 중이야.
- 대화창, 버튼, 메뉴, 체력 막대 B96~B99: 화면 틀을 손볼 때 쓸게.
