# 강호행 도트 요청서

마을, 건물, 지도, 인물 도트, 이펙트까지 그림 쪽을 전부 ChatGPT에 맡기기 위한 문서야. 이 문서는 `tools/pixel_doc.py`가 게임 자료에서 뽑아 만들어. 지금 게임에 실제로 쓰는 그림만 들어 있어.

## 먼저 읽을 것

**ChatGPT가 잘하는 것과 못하는 것**

- 건물 한 채, 나무, 가구, 전투 배경, 땅 텍스처, 지도 콘셉트는 잘 나와.
- 진짜 16픽셀 격자는 못 지켜. 도트처럼 보이지만 칸이 흔들려. 그래서 큰 그림으로 받아서 내가 도구로 줄여 넣어. 게임 안에서는 지금보다 두 배 고운 32픽셀 칸으로 들어가.
- 걷기 프레임은 칸마다 키와 옷이 조금씩 달라질 수 있어. 인물은 3열×3행까지만 요구해. 더 많이 시키면 무너져.
- 이펙트는 연속 동작이 약해. 프레임이 이어지지 않으면 프레임 수를 줄여서 쓸게.
- **지도 한 장을 통째로 게임에 깔 수는 없어.** 충돌 판정과 나무 뒤로 지나가는 앞뒤 가림이 안 되거든. 지도 그림은 배치 설계로 받고, 내가 그걸 보고 건물과 나무를 하나씩 놓아서 다시 만들어.

**순서**

1. 아래 "시험 3장"부터 뽑아서 나한테 보내 줘. 이게 게임에 잘 들어가는지 먼저 확인해야 나머지 수백 장이 헛일이 안 돼.
2. 시험을 통과하면 1순위부터 차례로 뽑아. 번호가 적힌 순서대로 보내 주면 내가 번호로 찾아 넣을게.
3. 한 묶음은 대화방 하나에서 뽑아. 대화방이 바뀌면 화풍이 달라져. 인물은 첫 사람 그림을 보여 주면서 "이 화풍 그대로"라고 말하면 잘 맞아.
4. 그림이 마음에 안 들면 그 번호만 다시 뽑으면 돼. 파일 이름은 신경 쓰지 않아도 돼.

**모든 대화방 첫 줄에 붙일 문장**

```
앞으로 그리는 그림은 전부 같은 게임에 들어가. 중국 무협 배경의 탑다운 RPG이고, 슈퍼패미컴 말기나 플레이스테이션 초기 2D 게임처럼 정갈한 도트 그림이야. 시점은 위에서 45도로 내려다본 3/4 시점. 외곽선은 어두운 색 1도트. 안티앨리어싱, 블러, 그라데이션, 반투명은 쓰지 마. 한 장에 32색 안쪽으로 그려. 글자, 워터마크, 테두리, 바닥 그림자는 넣지 마. 배경은 완전한 단색 마젠타(#FF00FF)로 칠하고, 마젠타는 그림 안에 쓰지 마. 일본 사무라이나 서양 판타지가 아니라 명나라 복식과 건축을 따라.
```

## 4순위: 인물 도트 (50명 × 2장)

인물마다 걷기 시트와 전투 시트를 한 장씩 뽑아. 같은 대화방에서 걷기 시트를 먼저 뽑고, 이어서 "방금 그 인물로" 전투 시트를 요청해. 앞의 12명이 주연이니 여기까지 먼저 해도 게임이 크게 달라져.

**걷기 시트 문장**

```
정사각형 한 장을 3열 3행으로 나눠 같은 인물을 9번 그려. 1열은 앞모습, 2열은 뒷모습, 3열은 왼쪽을 보는 옆모습. 1행은 차렷, 2행은 왼발 내딛는 걷기, 3행은 오른발 내딛는 걷기. 머리가 조금 큰 2.5등신이고 아홉 칸 모두 키, 머리 크기, 옷, 색이 완전히 같아야 해. 칸끼리 넉넉히 떼고, 겹치지 마.
```

**전투 시트 문장**

```
같은 인물을 정사각형 한 장에 3열 3행으로 9번 그려. 1열은 앞, 2열은 뒤, 3열은 왼쪽을 보는 옆모습. 1행은 양손을 크게 휘두르는 공격 자세, 2행은 뛰어오르는 자세, 3행은 양팔을 앞으로 모아 막는 자세. 무기는 들지 마. 무기는 따로 그려서 게임이 손에 붙여. 앞 그림과 같은 인물이고 2.5등신, 색도 같아야 해.
```
