# 새 화면: 지금부터 할 일 (한 번에)

이 문서는 작업을 맡은 Claude에게 주는 작업 순서다. 주인은 하나씩 확인해 줄 시간이 없다. **여기 적힌 것을 묻지 말고 끝까지 이어서 해.** 멈추고 물어볼 것은 맨 아래 "물어볼 것"에 적은 경우뿐이다.

## 일하는 방식

- 한 묶음이 끝날 때마다 시험을 돌리고, 화면을 찍어 `docs/ref/`의 기준 화면과 나란히 놓고 **네가 직접 보고 판단해.** 아래 "스스로 볼 것"에서 걸리면 고친 뒤 다음으로 가. 주인에게는 묶음이 끝날 때 한 번만, 주소와 다섯 줄 이내의 요약으로 알려.
- 그림은 주인이 ChatGPT로 받아 `art-src/chatgpt/`에 번호 이름으로 넣거나 대화에 올린다. 오면 바로 넣어. 안 온 것은 같은 규격의 임시 그림으로 두고 기다리지 마.
- 받은 그림은 네가 검사해. 볼 것: 칸 배치가 요청서(`docs/chatgpt-backgrounds.md`, `docs/chatgpt-characters.md`)와 같은가, 배경색이 깨끗이 지워지는가, 도트 굵기가 다른 그림과 맞는가, 이어 붙이는 무늬에 이음매가 보이는가, 인물은 줄였을 때 얼굴과 옷이 구분되는가. 쓸 수 없는 그림은 쓰지 말고, 요약에 "번호 + 다시 받을 때 ChatGPT에 붙일 문구"를 적어 줘.
- 컴퓨터로만 하는 게임이다. 주인 컴퓨터에서 초당 60장면이 나왔다. 휴대폰은 신경 쓰지 마. 효과를 아끼지 마.

## 묶음 1: 청하진을 기준 화면 수준으로

1. 받은 그림 넣기: `HR2`(처마·용마루 띠), `HW1`(살림집 벽 세 채), `HK2`(담 여섯), `HP2`(거리 채움 열둘). `art-src/chatgpt/README.md`에 칸 설명이 있다.
2. 집 키우기: 바닥 넓이는 그대로, 벽 높이를 사람 키의 두 배쯤, 지붕까지 서너 배. 문은 사람보다 조금 높게.
3. 지붕: 두께를 주고 처마를 벽 밖으로 내밀어. 처마 끝에 HR2 막새 띠, 꼭대기에 용마루 띠, 처마 밑은 어둡게. 박공은 HW1 옆벽 그림의 삼각형을 그대로 써(늘이지 마).
4. 배치 좁히기: 청하진만. 길 폭과 집 간격을 줄여 한 화면에 집이 서너 채 겹쳐 보이게. 문, 출구, 이야기 자리는 같이 옮기고 2D 화면도 같은 배치를 쓴다. reach, door, playthrough가 통과해야 한다.
5. 채우기: HP2와 HB11 소품, HK2 담과 울타리로 길가와 집 둘레를 채워. 집마다 마당 울타리, 문 옆 통이나 광주리, 길가 등롱 기둥. 길은 막지 마.
6. 빛: 낮의 그림자를 훨씬 진하게, 벽과 땅이 만나는 곳을 어둡게, 화면 가장자리를 어둡게. 기준 화면은 그늘이 거의 검다. 밝은 곳은 번지게.
7. 풀밭 색을 기준 화면처럼 더 푸르고 밝게 보정. 돌마당 무늬가 벽돌처럼 보이면 축척을 키워.
8. 화면 맨 앞에 흐린 덤불과 울타리(임시 그림이어도 됨).
9. 물: 강을 새 화면에 맞게(잔물결이 움직이고 하늘빛이 비치게). 그림(HG2)이 오기 전에는 코드로.
10. 예전 2.5등신 NPC는 새 인물 그림이 올 때까지 같은 키로 맞춰 덜 튀게.

끝나는 기준: 청하진 큰길에서 낮·저녁·밤을 찍어 기준 화면 옆에 놓았을 때 "같은 계열 게임"으로 보인다. 빈 풀밭이 화면의 3분의 1을 넘지 않는다.

## 묶음 2: 다른 지도로 넓히기

1. 그리기 층 정리(원래 1단계): 필드 그리기를 한 곳으로 모아 새 화면과 2D를 설정으로 오가게. 쿼터뷰는 걷어 낸다.
2. 모든 바깥 지도를 새 화면으로. 건물 종류마다 덩어리 규칙(벽 높이, 지붕 모양, 어느 벽·지붕 그림을 쓰는지)을 표 하나로 정해. 그림이 없는 건물은 임시 그림.
3. 배치 좁히기를 규칙으로: 청하진에서 한 손질을 다른 지도에 손으로 되풀이하지 말고, 지도를 읽어 빈 길 폭과 집 간격을 줄이는 변환을 만들어 적용해. 지도마다 reach, door를 돌려 깨지는 지도는 원래 배치로 두고 목록으로 남겨.
4. 채우기도 규칙으로: 집 둘레 울타리, 문 옆 소품, 길가 등롱 기둥, 풀 포기를 지도 종류(마을, 고을, 문파, 산중, 변방)에 따라 자동으로 놓아. 길과 문 앞은 비워.
5. 높낮이: 나루터에서 쓴 방식을 문파 기단, 성문 앞, 산길에 넣어.
6. 방 안: 뒷벽이 선 무대 모양으로. HI 그림이 오기 전에는 벽과 바닥을 임시 그림으로 세워.
7. 문, 출구 표시, 이름표, 말풍선, 날씨, 전쟁 효과까지 새 화면에서 돌게.

끝나는 기준: 이야기 처음부터 끝까지(playthrough) 새 화면으로 돌고, 2D 시험도 전부 통과한다.

## 묶음 3: 마무리

1. 먼 배경(HF1, HF2)과 앞 장식(HF3), 햇살 줄기, 먼지와 꽃잎.
2. 인물 그림이 오는 대로 넣기. 전투 화면도 같은 그림을 쓰게.
3. 강호 전도를 같은 방식으로.
4. 새 화면을 기본으로 켜고, 설정에서 2D로 돌아갈 수 있게.

## 스스로 볼 것 (묶음마다)

- 기준 화면과 나란히 놓고 가장 다른 점 세 가지를 적고, 그중 그림 없이 고칠 수 있는 것은 바로 고쳐.
- 사람이 건물에 가려지지 않는가. 문으로 들어가지는가. 주인공이 화면 안에 있는가.
- 새 그림과 임시 그림이 섞여도 크기와 밝기가 튀지 않는가.

## 물어볼 것 (이때만 멈춰)

- 이야기 내용이나 지도 연결(어느 문이 어디로 가는지)을 바꿔야 할 때.
- 시험을 통과시킬 방법이 없을 때.
- 묶음 1이 끝났을 때 한 번(화면을 보고 계속 갈지 정한다).
