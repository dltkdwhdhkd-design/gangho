쓰는 법 (이 칸은 나한테 하는 메모야. ChatGPT에는 `---` 아래부터 줘)

- 새 대화를 열고, **일검풍운결 낮 화면 한 장을 같이 올린 뒤** `---` 아래를 통째로 붙여.
- 그다음 번호를 하나씩 말해. 순서는 **HG1(땅) → HR1(지붕) → HW0(시험 집)** 먼저. 이 석 장을 Opus에게 줘서 화면에 입혀 보고, 괜찮으면 나머지를 받아.
- 1판(번호 HB)과 달라진 점: 배경도 굵은 도트 결로 받는다. 건물은 통짜 그림이 아니라 3D 상자에 입힐 부품(앞벽, 옆벽, 지붕 무늬)으로 받는다. 빛과 그림자는 그림에 넣지 않는다(게임이 넣는다). 배경색은 파랑.
- 1판으로 받은 살림 소품(석등, 우물, 수레 등 열두 가지)은 그대로 써도 되니 HP1은 건너뛰어도 돼.

---

이 문서는 게임 "강호행"에 넣을 배경 그림 요청서야. 첨부한 화면은 일검풍운결(逸劍風雲決, Wandering Sword)이고, 내 게임의 배경을 이 화면과 같은 결로 만들 거야. 아래 규칙을 지켜서 그려 줘.

- 내가 번호를 말하면 그 번호의 그림 **한 장만** 그려. "다음"이라고 하면 다음 번호를 그려.
- 모든 그림은 "공통 규칙"을 따라. 번호마다 적힌 문장은 그 위에 더해지는 내용이야.
- 앞서 그린 그림과 그림체, 도트 굵기, 색감을 똑같이 이어 가.
- 그림에 글자, 번호, 워터마크, 칸 나누는 선을 넣지 마. 설명은 그림 밖 대화로만 해.
- 다 그리면 파일 이름을 번호로 알려 줘(예: `HW3.png`).

## 공통 규칙

```
앞으로 그리는 그림은 전부 같은 게임에 들어가. 명나라를 배경으로 한 무협 RPG이고, 첨부한 일검풍운결(Wandering Sword) 화면과 같은 HD-2D 게임이야. 아래를 모든 그림에서 지켜.

1. 질감: 매끈한 그림이 아니라 굵은 도트가 눈에 보이는 픽셀 아트로 그려. 첨부한 화면의 건물, 돌바닥, 나무와 같은 도트 굵기, 같은 색 수, 같은 색감(채도를 조금 낮춘 따뜻한 자연색). 기와 한 장, 돌 하나, 나뭇결이 도트로 또렷이 구분돼야 해. 흐림, 번짐, 부드러운 그라데이션을 쓰지 마.
2. 빛: 흐린 낮처럼 고르고 중립적인 밝기로 칠해. 햇빛 방향, 노을빛, 바닥에 떨어진 그림자, 빛 번짐을 넣지 마. 게임이 시간에 따라 빛과 그림자를 따로 입혀. 물체 자체의 굴곡을 보여 주는 약한 명암만 넣어.
3. 배경색: 그림이 아닌 빈 곳은 순수한 파랑(#0000FF) 한 색으로 칠해. 그림 안에는 그 파랑을 쓰지 마. 그림 가장자리는 파랑과 섞이지 않게 또렷하게 끊어.
4. 여러 가지를 한 장에 그릴 때는 칸마다 하나씩, 칸 가운데에, 서로 닿지 않게 넉넉히 떼어. 한 장 안에서는 축척을 똑같이 맞춰.
5. 사람, 글자, 워터마크, 테두리는 넣지 마. 현판은 글자 없이 비워 둬.
6. 일본풍이나 서양 판타지가 아니라 명나라 건축과 살림을 따라(기와지붕, 두공, 격자 창, 붉은 기둥, 돌 기단).
```

## 2순위: 지붕

건물은 게임에서 3D 상자로 만들고 면마다 그림을 입혀. 지붕은 기운 판에 무늬를 반복해 입히니까 무늬로 받아.

**HR1. 지붕 무늬 여섯**
```
정사각형 한 장을 3열 2행으로 나눠 지붕 무늬 여섯 가지를 그려. 칸마다 꽉 채워 그리고 칸 사이는 가는 파랑 선으로만 구분해. 지붕 면을 똑바로 마주 본 평면이야(원근 없음, 기울임 없음). 기와 골은 위에서 아래로 곧게 내려와. 좌우와 위아래로 이어 붙여도 이음매가 안 보이게. 빛과 그림자 없이 고른 밝기.
여섯 가지: (1) 주황빛 기와, 군데군데 이끼 (2) 검푸른 기와 (3) 누런 초가 짚, 가로로 새끼줄이 지나감 (4) 낡은 잿빛 판자 지붕 (5) 흙을 바른 평평한 지붕 (6) 눈이 얹힌 검푸른 기와
```

**HR2. 처마와 용마루 띠**
```
가로로 긴 한 장을 1열 6행으로 나눠 가로 띠 여섯 줄을 그려. 띠마다 좌우로 이어 붙여도 이음매가 안 보이게. 정면에서 똑바로 본 모습. 띠 위아래 빈 곳은 파랑.
여섯 줄: (1) 주황 기와 처마 끝, 둥근 막새기와가 한 줄로 늘어섬 (2) 검푸른 기와 처마 끝, 막새기와 한 줄 (3) 초가 처마 끝, 짚이 고르지 않게 늘어짐 (4) 판자 지붕 끝 (5) 기와 용마루, 지붕 꼭대기에 얹는 둥근 기와 줄 (6) 처마 밑 서까래와 두공이 늘어선 띠
```


## 5순위: 나무, 바위, 살림

## 6순위: 먼 배경과 앞 장식

**HF1. 먼 배경 넷** (파랑 배경 없이 그림 전체를 채워)
```
가로로 아주 긴 그림(21:9)을 한 장씩, 네 장 그려 줘. 게임 화면 맨 뒤에 깔리는 먼 풍경이야. 같은 굵은 도트 결. 사람과 건물은 넣지 말고, 아래쪽 4분의 1은 옅은 안개로 비워 둬. 왼쪽 끝과 오른쪽 끝이 자연스럽게 이어지게. 이 그림만은 먼 곳이 뿌옇게 옅어지는 표현을 써도 돼.
(1) 강 건너 겹겹의 푸른 산과 옅은 구름 (2) 깎아지른 바위 봉우리와 구름바다, 소나무 (3) 끝없는 모래 언덕과 먼 바위산, 누런 하늘 (4) 눈 덮인 산맥과 잿빛 하늘
```

**HF2. 먼 지붕 줄**
```
가로로 아주 긴 그림(21:9) 한 장. 안개 속에 겹겹이 선 먼 기와지붕과 나무 꼭대기의 줄이야. 화면 아래쪽 절반에만 그리고 위쪽은 파랑으로 비워. 색은 옅고 뿌옇게. 왼쪽 끝과 오른쪽 끝이 이어지게.
```

**HF3. 앞 장식 넷**
```
가로로 긴 한 장을 2열 2행으로 나눠 네 가지를 그려. 게임 화면 맨 앞을 살짝 가리는 장식이야. 빈 곳은 파랑.
네 가지: (1) 아래에서 올라온 풀과 들꽃 (2) 옆에서 뻗어 나온 소나무 가지 (3) 옆에서 뻗어 나온 흰 매화 가지 (4) 차양 친 좌판의 지붕 윗면(위에서 내려다본 누런 천 차양 둘)
```

## 7순위: 방 안

**HI1. 방 바닥과 벽**
```
정사각형 한 장을 3열 2행으로 나눠 여섯 가지를 그려. 칸마다 꽉 채우고 칸 사이는 가는 파랑 선. 1행은 위에서 똑바로 내려다본 방 바닥 무늬(사방으로 이어 붙일 수 있게): (1) 나무 마루 (2) 돌 바닥 (3) 붉은 융단을 깐 마루. 2행은 정면에서 똑바로 본 방 안쪽 벽 한 토막(좌우로 이어 붙일 수 있게): (4) 흰 회벽과 나무 기둥, 격자 창 (5) 어두운 판자벽, 걸린 등 (6) 붉은 기둥과 금빛 장식의 전각 벽
```

**HI2~HI7. 방 여섯 가지** (방마다 한 장, 파랑 배경 없이 그림 전체를 채워)
```
게임의 방 안 배경을 한 장 그려. 가로로 긴 그림(16:9). 같은 굵은 도트 결. 정면에서 30도쯤 내려다본 무대 모양: 뒷벽이 화면 위쪽에 서 있고 양옆 벽이 조금 보이고 앞벽은 없어. 바닥이 화면의 아래 3분의 2를 차지하고, 가운데는 사람이 걸어 다니게 비워 둬. 가구는 뒷벽과 양옆 벽에 붙여. 문은 아래쪽 가운데에 문턱만 보이게. 사람은 넣지 마. 이 그림만은 창으로 드는 약한 빛을 넣어도 돼.
방: [아래에서 하나]
```
- HI2 객잔 일층: 뒷벽에 술독 선반과 계산대, 네모 탁자 넷, 한쪽에 이층 계단
- HI3 살림집: 구들과 이불, 작은 탁자, 부뚜막, 물독
- HI4 약방: 뒷벽 가득 약장, 계산대, 침상 하나, 약초 말리는 채반
- HI5 대장간: 화덕과 풀무, 모루, 벽에 걸린 연장과 칼

- HI7 제자 숙소: 양옆 벽을 따라 소박한 나무 침상이 줄지어 있고 가운데가 비어 있음
