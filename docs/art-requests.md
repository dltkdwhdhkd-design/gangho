# 강호행 이미지 요청문

> 지금 받을 그림은 사람(일러스트·도트)은 `docs/gemini-now.md`, 건물·땅·소품은 `docs/chatgpt-now.md`에 모아 둔다. 이 문서는 예전 기록이다.

ChatGPT에 붙여 넣는 요청문입니다. 코드 칸 오른쪽 위의 복사 단추를 쓰면 됩니다.

## 쓰는 순서

1. 새 대화를 열고 아래 **공통 규칙**부터 붙입니다.
2. 1순위부터 한 장씩 요청합니다. 그림체가 어긋나면 "첫 그림과 같은 그림체로 다시"라고 하면 됩니다.
3. 받은 그림은 제목에 적힌 이름 그대로 저장합니다. 예: `yun_n.png`
4. 저장소 `assets/art/` 폴더에 올리거나 채팅에 첨부하면 게임에 넣겠습니다. 단색 배경으로 받았다면 배경은 제가 지웁니다.

대화 화면 그림은 세로 640px로 표시되고, 오른쪽에 설 때는 좌우가 뒤집힙니다. 그림 속 글자나 무늬가 뒤집혀도 괜찮게 받아 주세요. 1024×1536이면 비율이 맞습니다. `_n`은 기본 표정입니다.

ChatGPT가 노출 때문에 거절하면 `파인`, `트인` 같은 표현을 빼고 `몸선이 드러나는 옷`과 `볼륨 있는 몸매`만 남겨 다시 요청하세요.

## 공통 규칙

```text
지금부터 내 게임에 들어갈 인물 일러스트를 한 번에 한 장씩 그려 줘. 아래 규칙은 모든 그림에 똑같이 적용해.

- 게임: 한국 무협 도트 게임 '강호행'. 대화할 때 화면 양쪽에 서는 인물 그림이야.
- 그림체: 한국 웹소설 표지풍의 깔끔한 2D 일러스트. 선이 또렷하고, 셀화 채색에 명암을 가볍게 더한 정도. 사진풍과 3D풍은 금지.
- 복장: 가상의 동양 고대 무협. 명나라풍과 한복풍을 섞은 무복. 기모노나 사무라이 갑옷은 금지.
- 구도: 허벅지 위까지 보이는 한 사람. 몸은 오른쪽으로 살짝만 돌리고, 얼굴과 시선은 거의 정면을 봐. 플레이어와 눈이 마주쳐야 해. 머리 위에 여백을 조금 두고 머리와 손이 잘리지 않게.
- 크기: 세로 1024×1536. 배경은 완전히 투명한 PNG. 투명이 안 되면 무늬 없는 단색 회색 배경.
- 글자, 서명, 워터마크, 테두리는 넣지 마.
- 모든 인물은 성인이야. 여성 인물은 성숙한 성인 여성의 볼륨 있는 몸매로 그리고, 설명에 적힌 의상의 노출과 몸선을 살려 줘.

첫 그림이 정해지면 그 뒤로는 모든 그림을 같은 그림체로 유지해. 알겠으면 그림을 그리지 말고 "준비됐어"라고만 답해.
```

## 이미 받은 그림 고치기

옆을 너무 많이 본 그림은 다시 그릴 필요 없이 첨부하고 이 문장을 붙입니다.

```text
첨부한 그림과 같은 인물, 같은 옷, 같은 그림체로 그려 줘. 몸은 오른쪽으로 살짝만 돌리고, 얼굴과 시선은 거의 정면을 보게 해 줘. 크기와 투명 배경은 그대로 유지해.
```
