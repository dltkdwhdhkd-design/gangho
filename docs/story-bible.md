# 강호행 전체 줄거리

이 문서가 이야기의 기준입니다. 장을 쓰기 전에 읽고, 설정이 바뀌면 여기부터 고칩니다.

## 1. 분량 기준

| 항목 | 기준 |
|---|---|
| 전체 | 5부 26장, 약 20~25시간 |
| 한 부 | 5장, 4~5시간 |
| 한 장 | 약 1시간. 대사 8천~1만 자, 전투 6~8번, 의뢰나 호감 사건 2~3개 |
| 한 부 합계 | 대사 4~5만 자, 전투 30~40번, 새 지도 6~10곳, 보스 5~6명 |
| 전체 합계 | 대사 20~25만 자 |

읽는 시간은 플레이의 40% 정도로 잡았습니다. 나머지는 전투, 이동, 제작, 낚시, 연애입니다.

## 2. 세력 구도

세 갈래가 끝까지 유지됩니다. 어느 쪽도 단순한 선이나 악이 아닙니다.

**정파: 정천맹.** 구파일방과 오대세가의 맹약. 질서를 말하지만 십칠 년 전 월하문을 불태웠습니다. 체면 때문에 사과를 못 합니다.

**사파: 흑도맹.** 정파가 받아 주지 않은 사람들의 연합입니다. 주먹이 법이지만 약속은 지킵니다. 본격적인 적대는 2부부터입니다.
- 녹림 칠십이채: 산의 산채 연합. 총채주 구양철. 흑풍채도 여기 속합니다.
- 장강수로채: 강의 수적. 총채주 오강, 강남 분타주 낭리비어 위충.
- 하오문: 도박, 기루, 도둑의 정보망. 문주 만화부인, 청하진 접선인 백랑.
- 오독문: 독의 문파. 사천당가와 앙숙.
- 혈의방: 살수 집단. 방주 혈수 막고.
- 맹주: 패천도 사마웅. 2부의 주적이자 4부의 동맹입니다.

**마교: 천마신교.** 서역 천산 너머의 흑운궁이 총단입니다. 교주 천마 혁련무극은 삼백 년 전 봉인되었습니다. 그를 받드는 네 마왕이 있습니다.
- 심마 연경추: 사람 마음을 움직이는 자. 정체를 숨기고 정천맹주가 되었습니다.
- 혈마, 빙마, 귀마: 4부에 차례로 등장합니다.
- 무면당: 심마 직속의 잠입 조직. 강호가 무면회라 부르는 얼굴 없는 자들입니다.

**주인공의 자리.** 점소이는 정파도 사파도 아닙니다. 양쪽의 밥을 나른 사람이라 양쪽 사람을 다 압니다. 정파와 사파를 한자리에 앉히는 일이 이 이야기의 축입니다.

## 3. 세계의 비밀

- 삼백 년 전 낙월선자가 천마를 천산 아래 봉인했고, 그 제자들이 월하문을 세워 봉인을 지켰습니다.
- 월하칠식은 무공서이자 봉인의 열쇠입니다. 일곱 장이 모여 일곱 초식이 한 몸에서 펼쳐지면 봉인이 풀립니다.
- 십칠 년 전의 멸문은 연경추가 꾸몄습니다. 정천맹을 움직여 월하문을 치게 하고 일곱 장을 찾았지만, 낱장은 찢겨 흩어졌습니다.
- 연경추는 그래서 주인공을 일부러 살려 두고 낱장을 모으게 합니다. 주인공이 강해질수록 천마가 가까워집니다.
- 마지막 반전: 제칠식 낙월로는 천마를 벨 수 없습니다. 칠식의 맨 앞, 찢기지 않은 서문이 진짜 시작입니다. “허리를 세우고, 왼발로 밀고, 오른발은 따라오게 둔다.” 첫 장면의 걸레질이 마지막 초식입니다.

## 4. 인물의 흐름

| 인물 | 흐름 |
|---|---|
| 주인공 | 점소이 → 강호 초행 → 정사를 잇는 사람 → 천마를 벤 사람 → 다시 객잔 |
| 곽 아주머니 | 1~3부 납치 → 3부 말 구출 → 5부 객잔 방어전에서 국자를 든다 |
| 백 노인 | 1부에 사라짐 → 3부 재회, 내통 고백 → 4부 봉인을 지키다 죽음 |
| 월천(여우 가면) | 3부 정체 공개, 맹주에게 찔리고 시신이 사라짐 → 4부 마장으로 재등장 → 5부 제정신으로 돌아와 희생 |
| 윤설 | 의원 → 4부 마교의 역병 혈우를 막는 중심 |
| 소연하 | 사부를 찾음 → 4부에서 사부가 빙마가 되었음을 앎 → 직접 벤다 |
| 철우 | 파계승 → 4부 소림 산문을 끝까지 지킴. 문을 부수던 사람이 문을 지키는 장면 |
| 맹호 | 1부 동네 산채의 두목 → 2부 녹림 전선에서 재회 → 3부 주인공을 구하고 희생 |
| 위충 | 1부 떠돌이 수적 두목 → 2부 장강수로채 소속으로 재등장. 살려 주었다면 은혜를 갚음 |
| 백랑 | 1부 도박장 주인 → 2부에서 하오문 간부임이 드러남 → 4부 만화부인 뒤를 이음 |
| 사마웅 | 2부 주적 → 3부 담판 → 4부 동맹 → 5부 천산에서 마장을 막고 전사 |
| 연경추 | 1~2부 존경받는 맹주 → 3부 말 정체 공개, 패배하지만 일곱 장을 천산으로 보냄 → 4부 말 최후 |

## 5. 다섯 부의 줄거리

### 1부 객잔의 점소이 (주인공의 성장, 문파와 기연)
사파와의 전면 대립은 아직 없습니다. 주인공이 누구인지 알아 가고, 강호를 돌아다니며 사람과 무공을 만납니다. 수적과 산적은 동네 사건일 뿐입니다.
1. 달맞이 객잔: 걸레질, 방값, 왈패, 흑의인, 곽 아주머니 납치
2. 타다 남은 객잔: 윤설, 대숲 석상의 첫 기연, 떠돌이 수적 소동, 하오문 백랑
3. 우물 아래: 동네 산채 흑풍채, 맹호, 위패와 출생의 비밀
4. 구름 위의 칼: 창운산 입문, 소연하, 문주의 독, 위문상
5. 강호 유람: 소림 장경각 청소 기연, 십팔나한진, 화산 벼랑 추락과 동굴 기연
6. 천하비무: 구화성, 구파일방과 오대세가의 대표들, 철우, 대회 우승, 달거울. 마지막 밤, 멀리 불길이 오른다

### 2부 흑도맹 (사파와의 진짜 적대)
이제야 사파가 정면의 적이 됩니다. 1부에서 스친 맹호와 위충, 백랑이 다른 얼굴로 돌아옵니다.
1. 구화성의 밤: 흑도맹의 대회장 습격, 맹주의 토벌령, 정사대전 개전
2. 강을 건너는 사람들: 전선 배치, 피난민, 장강수로채와의 수전
3. 녹림의 깃발: 칠십이채 공략, 맹호와의 재회
4. 혈의방: 살수전, 동료의 부상, 오독문과 사천당가의 싸움
5. 패천도: 사마웅과의 결전. 주인공이 패하거나 물러나고, 전쟁을 부추긴 자가 따로 있음을 앎

### 3부 달이 진 골짜기 (진실)
전쟁의 배후를 쫓으면서 정파 안의 썩은 곳을 봅니다.
1. 정천맹의 균열: 구파일방과 오대세가의 내분
2. 두 번째 담판: 사마웅과 다시 만남, 맹호의 희생
3. 달거울의 글: 십칠 년 전 기록 추적, 제갈세가의 명령서
4. 월하곡: 흔적, 원혼, 백 노인의 고백, 호면의 정체
5. 낙월의 밤: 맹주의 배신, 일곱 장 탈취, 곽 아주머니 구출. 마지막에 달이 붉게 먹힌다

### 4부 서역의 달 (마교의 등장)
1. 붉은 달: 정천맹 붕괴, 마교군의 중원 침공, 역병 혈우
2. 합석: 정파와 사파를 한 객잔에 앉히는 협상. 이 이야기에서 가장 큰 말싸움
3. 소림의 문: 철우의 마지막 싸움 (배우자라면 다른 길로 살아남음)
4. 비단길: 사막 원정, 혈마, 빙마와 소연하의 사부
5. 천산 입구: 귀마, 재등장한 월천, 백 노인의 죽음, 연경추의 최후. 봉인이 풀린다

### 5부 낙월 (최종전)
1. 천마 재림: 첫 패배. 칠식이 통하지 않음
2. 객잔으로: 무공을 잃은 주인공의 귀향, 걸레질, 서문의 비밀
3. 달맞이 객잔 방어전: 전쟁이 청하진까지 옴. 사람들이 모두 모임
4. 흑운궁: 최종 돌입, 사마웅의 전사, 월천의 희생
5. 낙월: 천마와의 결전, 평판과 인연에 따른 엔딩

## 7. 지금 게임과의 관계

| 지금 내용 | 자리 |
|---|---|
| 프롤로그 | 1부 1장 |
| 대숲길, 수적 소동 | 1부 2장 |
| 흑풍채, 우물 | 1부 3장 |
| 창운산 | 1부 4장 |
| 소림과 화산 벼랑 | 1부 5장 |
| 구화성 비무대회 | 1부 6장 |
| 월하곡과 맹주전 | 3부 4~5장 |

지금 들어간 내용은 뼈대이고, 장을 쓸 때마다 사이에 새 장을 끼워 넣어 늘립니다. 그래서 작업 중에도 게임은 끝까지 플레이할 수 있습니다.

## 8. 함께 늘려야 할 체계
- 경지와 성 상한을 60성 정도로 올리고 적 능력치를 부별로 나눕니다.
- 평판은 정파와 사파 두 축으로 쌓이고, 3부 담판과 4부 합석, 엔딩이 달라집니다.
- 2부부터 동료가 전투에 동행하고, 부마다 새 지역과 무기 등급이 추가됩니다.
