# 강호행: 못 받은 그림 (인물·이벤트 장면)

인물과 이벤트 장면 쪽에서 아직 못 받은 것만 모았어. 배경과 이펙트는 [missing-bg-fx.md](missing-bg-fx.md)에 따로 있어. 그림을 넣을 때마다 다시 뽑으니까, 여기 남은 건 아직 게임에 없는 거야.

| 묶음 | 남은 수 | 어느 대화방에서 |
|---|---|---|
| [1. 대화 일러스트](#1-대화-일러스트) | 인물 3장, 표정 4장 | 인물 일러스트를 뽑던 대화방 |
| [2. 장면 그림](#2-장면-그림) | 43장 | 장면 그림을 뽑던 대화방 |
| [3. 도트 인물](#3-도트-인물) | 인물 13명(2장씩), 몬스터와 동물 16장 | 도트 인물을 뽑던 대화방 |
| [4. 대각선 걷기](#4-대각선-걷기) | 51장 (없어도 게임은 돌아가) | 도트 인물을 뽑던 대화방 |

예전 대화방이 남아 있으면 거기서 이어서 하는 게 그림체가 제일 잘 맞아. 새 대화방을 열 때는 각 묶음 맨 앞의 문장부터 붙이고, 이미 받은 그림 한 장을 같이 올려서 "이 그림체 그대로"라고 해 줘.

파일 이름은 제목에 적힌 대로 저장해 줘. 이름이 달라도 누구인지만 알 수 있으면 내가 찾아 넣을게.

## 1. 대화 일러스트

새 대화방이면 이 규칙부터 붙여.

```text
지금부터 내 게임에 들어갈 인물 일러스트를 한 번에 한 장씩 그려 줘. 아래 규칙은 모든 그림에 똑같이 적용해.

- 게임: 한국 무협 도트 게임 '강호행'. 대화할 때 화면 양쪽에 서는 인물 그림이야.
- 그림체: 한국 웹소설 표지풍의 깔끔한 2D 일러스트. 선이 또렷하고, 셀화 채색에 명암을 가볍게 더한 정도. 사진풍과 3D풍은 금지.
- 복장: 가상의 동양 고대 무협. 명나라풍과 한복풍을 섞은 무복. 기모노나 사무라이 갑옷은 금지.
- 구도: 허벅지 위까지 보이는 한 사람. 몸은 오른쪽으로 살짝만 돌리고, 얼굴과 시선은 거의 정면을 봐. 플레이어와 눈이 마주쳐야 해. 머리 위에 여백을 조금 두고 머리와 손이 잘리지 않게.
- 크기: 세로 1024×1536. 배경은 완전히 투명한 PNG. 투명이 안 되면 무늬 없는 단색 회색 배경.
- 글자, 서명, 워터마크, 테두리는 넣지 마.
- 모든 인물은 성인이야. 여성 인물은 성숙한 성인 여성의 볼륨 있는 몸매로 그리고, 설명에 적힌 의상의 노출과 몸선을 살려 줘.

첫 그림이 정해지면 그 뒤로는 모든 그림을 같은 그림체로 유지해. 알겠으면 그림을 그리지 말고 "준비됐어"라고만 답해.
```

## 2. 장면 그림

가로 그림이야. 새 대화방이면 인물 일러스트 한 장을 먼저 올려서 그림체를 맞추고 이 규칙을 붙여. 첨부가 적힌 장면은 그 인물 그림을 같이 올려 줘. 원본 PNG가 없으면 저장소 `assets/art/`에 같은 이름으로 있어.

```text
이번에는 게임의 장면 그림을 그려 줘. 지금까지의 그림체를 유지하고 아래 규칙을 지켜.

- 크기: 가로 1536×1024. 배경까지 꽉 찬 그림. 투명 배경 아님.
- 인물은 작게 넣거나 뒷모습으로. 풍경과 분위기가 중심이야.
- 화면 가운데에 글자가 올라가니 가운데는 어둡고 복잡하지 않게.
- 글자, 서명, 워터마크, 테두리는 넣지 마. 피와 상처는 직접 보여 주지 마.

알겠으면 그림을 그리지 말고 "준비됐어"라고만 답해.
```

## 3. 도트 인물

번호는 원래 요청서와 같아. 새 대화방이면 이 문장부터 붙여.

```text
앞으로 그리는 그림은 전부 같은 게임에 들어가. 중국 무협 배경의 탑다운 RPG이고, 슈퍼패미컴 말기나 플레이스테이션 초기 2D 게임처럼 정갈한 도트 그림이야. 시점은 위에서 45도로 내려다본 3/4 시점. 외곽선은 어두운 색 1도트. 안티앨리어싱, 블러, 그라데이션, 반투명은 쓰지 마. 한 장에 32색 안쪽으로 그려. 글자, 워터마크, 테두리, 바닥 그림자는 넣지 마. 배경은 완전한 단색 마젠타(#FF00FF)로 칠하고, 마젠타는 그림 안에 쓰지 마. 일본 사무라이나 서양 판타지가 아니라 명나라 복식과 건축을 따라.
```

인물마다 아래 칸을 붙여 걷기 시트를 먼저 뽑고, 같은 대화에서 바로 이 전투 시트 문장을 붙여. 전투 시트 문장은 모든 인물에 똑같아.

**전투 시트 문장**

```text
같은 인물을 정사각형 한 장에 3열 3행으로 9번 그려. 1열은 앞, 2열은 뒤, 3열은 왼쪽을 보는 옆모습. 1행은 양손을 크게 휘두르는 공격 자세, 2행은 뛰어오르는 자세, 3행은 양팔을 앞으로 모아 막는 자세. 무기는 들지 마. 무기는 따로 그려서 게임이 손에 붙여. 앞 그림과 같은 인물이고 2.5등신, 색도 같아야 해.
```

## 4. 대각선 걷기

비스듬히 걸을 때 쓰는 그림이야. 없으면 옆모습으로 걸어. 그 인물의 걷기 시트를 뽑은 대화방에서 걷기 시트를 보여 주고 이 문장을 붙여. 주인공(C68)부터 해 보고 괜찮으면 나머지를 해. 걷기 시트를 아직 안 뽑은 인물은 3번 묶음부터 해야 해.

