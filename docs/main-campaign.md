# 강호행 본편

달맞이 객잔 점소이는 불탄 객잔에서 양어머니 곽씨의 행방을 찾으러 나간다. 처음 상대하는 적은 강호를 뒤엎으려는 마두가 아니다. 불까지 다 꺼지고 나서 소방삯을 받으러 온 정파의 칼잡이다. 주인공은 그날 나루에서 배운 셈법으로 장강 전쟁의 배를 세고, 마침내 천마 앞에서 누구의 밥그릇이 비었는지를 묻는다.

## 아홉 부와 마흔다섯 장

본문의 결말까지 밝힌다. 각 행의 장 이름은 게임에 나오는 순서다.

| 부 | 제1장부터 제5장까지 | 사건 |
|---|---|---|
| 1부 객잔의 낭인 | 빈 국수 그릇 → 재 속의 발자국 → 빈 배에도 매긴 세 → 깃발을 판 자 → 강호로 나가는 아침 | 청하진 객잔이 타고 곽씨가 사라진다. 점소이는 젖은 장옷, 바깥에서 건 빗장, 안에서 풀린 매듭을 보며 곽씨가 마지막까지 다른 사람들을 내보냈음을 알게 된다. 사공 문옥의 배를 타고 처음 강호로 나선다. |
| 2부 구름 위의 칼 | 산문 밑의 줄 → 칼집째 막은 길 → 약탕의 두 주인 → 장서각의 젖은 벽 → 한규가 벗은 완장 | 창운문 집사 한규는 강을 지키는 데 돈이 든다며 양민의 빈 배에까지 호위세를 매긴다. 소연하는 나무꾼 딸 대신 칼을 받고, 고진은 문파 체면에 손해가 될 증인을 세운다. 주인공이 세금과 약값의 행방을 밝혀낸 뒤에도 한규에게는 피해를 갚아야 할 일이 남는다. |
| 3부 강호 유람 | 소림에 남은 식객 → 칼자국 아래 나룻길 → 강 위의 두 깃발 → 맹주의 빈 잔 → 비무대 아래의 길 | 소림과 화산을 돌며 문밖에 남은 피난민과 뱃사람들을 만난다. 정파 상선과 사파 소금배가 서로 먼저 쳤다고 주장한다. 비무가 한창인 구화성에서 주인공은 구경꾼을 실었다던 배가 반대쪽에 닻을 내리는 광경을 본다. |
| 4부 금 간 깃발 | 네 갈래의 증언 → 돌아오지 않는 곡선 → 사람 값이 적힌 칼 → 끊으라는 전령 → 강을 건 사슬 | 쇄강채주 목진악은 산 사람과 죽은 사람에게까지 도강세를 매긴다. 주인공이 고른 진영에 따라 군영, 선창, 교단, 길손들 사이에서 들을 수 있는 증언이 달라진다. 두 편에 동시에 다리를 끊으라는 전령이 도착하고, 피난민들은 아직 다리 위에 있다. |
| 5부 장강의 전쟁 | 장강이 갈라지던 날 → 무창의 밤배 → 세 전선의 아침 → 쇄강채 수문 → 쇄강도 목진악 | 강을 독차지하려는 목진악이 물목에 사슬을 건다. 주인공은 무창의 밤배를 호송하고, 수문을 열고, 불붙은 갑판에서 목진악과 결투한다. 강은 열렸지만 종을 실어 나르던 이들은 이미 떠났다. |
| 6부 달이 진 골짜기 | 달거울의 뒤편 → 진 배의 목격자 → 열어 준 사람 → 여우 가면의 매듭 → 재 속에서 난 종소리 | 사마웅과 함께 패전한 배들을 좇는다. 곽씨와 월천이 사람들을 몰래 빼낸 길이 드러난다. 주인공은 월하문 참사와 자신의 과거를 마주하고, 옛 제단에서 심마 연경추가 전쟁 중 사람들에게 종을 시험한 기록을 찾는다. |
| 7부 붉은 달 | 밤에 뜨는 둘째 달 → 혈우를 피하는 법 → 같은 상에 앉은 사람들 → 열린 소림 산문 → 돌려세운 전선 | 붉은 비를 맞은 사람이 가족의 이름을 잊는다. 윤설은 아이가 좋아하던 음식부터 묻고, 곽씨는 서로를 죽인 사람들 앞에 긴 상을 놓는다. 정사 양쪽은 희생자 가족의 말을 듣고서야 피난민이 몰린 소림 산문을 함께 지킨다. |
| 8부 서역의 달 | 모래 위에 남은 수레길 → 빈 칼집의 임자 → 눈길에 돌아온 이 → 천산의 빗장 → 심마의 마지막 셈 | 대상과 사막을 건너 천산으로 간다. 눈길에서 월천의 발걸음과 종의 빠진 한 박자가 맞아떨어진다. 주인공이 연경추의 제단을 깨려 드는 것까지 그의 셈에 들어 있었다. 천마 혁련무극이 깨어난다. |
| 9부 낙월 | 돌아오는 패잔병 → 왼발을 미는 일 → 객잔을 지키는 사람들 → 흑운궁의 세 문 → 달이 지는 밥상 | 천마에게 패한 주인공은 객잔에서 다시 걷고 국그릇 드는 법부터 배운다. 동료들과 피난길을 열고, 흩어진 단서로 흑운궁의 세 문을 지나 천마와 결전을 치른다. 돌아와 객잔을 맡을지, 강호를 이끌지, 봉인을 지킬지, 다시 떠날지는 플레이어가 정한다. 마교에 선 주인공에게는 결전 뒤 천마의 그릇을 받는 선택도 있다. |

## 전쟁을 겪는 네 가지 길

4부와 5부에서는 각 장의 첫 증인, 증인을 만나는 장소, 그 자리에서만 드러나는 물증이 갈린다. 같은 사건을 뒤쫓아도 그날 누구의 이름을 먼저 듣느냐가 다르다.

| 주인공의 길 | 전쟁에서 보는 것 |
|---|---|
| 정파 | 장부를 쓰는 이와 명을 집행하는 이 사이에서 징발과 호위를 가른다. 문파의 도장이 찍힌 명령도 증언과 대조한다. |
| 사파 | 선창과 수채 안으로 들어간다. 목진악과 함께 묶여 불리면서도 배와 노꾼을 살리려는 사파 사람들을 만난다. |
| 마교 | 제단의 봉헌물과 교단 안의 전달 경로를 좇는다. 명에 따른 사람과 명령을 그대로 따르지 않은 사람이 남긴 흔적이 갈린다. |
| 낭인 | 문중 장부에 들지 않는 길잡이와 주모, 뱃사람에게 묻는다. 길에서 만난 사람이 제 이름을 대고 나서야 성립하는 증언이 있다. |

## 초반 단서가 돌아오는 곳

- **세 홈 놋전**을 처음 본 아이들은 딱지처럼 갖고 논다. 사공의 손을 거쳐 배 밑창과 통행권의 표식이 드러나고, 흑운궁 첫 문 앞에서 놋틀과 맞는다.
- **거꾸로 맨 흰 끈**은 누가 사람을 끌고 갔느냐를 묻게 한다. 전쟁 중 돛장이가 짧은 끝을 어느 쪽에 남겼는지 짚어 준다. 월하곡에서 그 매듭을 지은 사람을 알고, 흑운궁에서 갇힌 사람들이 스스로 풀 수 있게 남긴 뜻을 되살린다.
- **종의 빈 박자**를 처음 기억하는 사람은 무림 고수가 아니라 나룻배 사공이다. 사라진 소리에도 놀라지 않은 참새, 배 안의 생존자, 천산 눈길에서 멈칫한 월천이 한 줄로 이어진다. 마지막 문에서 종의 명령이 끊긴 한 박에 사람의 목소리가 들어간다.

## 본편 한 회차의 시간 예산

보통 난이도 초회에 **약 20시간**을 목표로 했다. 아래는 콘텐츠를 설계할 때 잡은 시간이다. 본편의 한 진영만 세며 행록, 의뢰, 인연, 반복 사냥은 합계에서 뺐다. 한 부에 다섯 장이 있고, 각 장의 현장 세 곳과 장말의 선택을 마쳐야 다음 부로 넘어간다.

| 포함한 플레이 | 기준 | 시간 |
|---|---|---:|
| 기존 본편 대화, 이동, 전투, 결말 | 한 진영 경로의 기존 설계 범위인 6~8시간의 중간값 | 7시간 |
| 새 필수 현장의 이동, 증언, 물증 확인과 추리 | 135곳 × 3분 30초 | 7시간 52분 30초 |
| 호송, 답사, 전령, 수문, 운반 작전 | 90회 × 2분 30초 | 3시간 45분 |
| 현장 전투와 목진악전 | 46회 × 1분 30초 | 1시간 9분 |
| 장말 결정과 그 결과 | 45회 × 30초 | 22분 30초 |
| **설계 합계** | | **20시간 9분** |

45장과 네 진영의 분기 진행, 선택 사건을 건너뛴 결말 진입, 조사 중 저장 복귀는 자동 검사했다. 90개 작전의 최단 해법을 합치면 2,991수다. 대사 넘김 속도, 길을 아는지, 전투에 얼마나 걸리는지에 따라 실제 시간은 달라진다. 사람이 처음부터 엔딩까지 플레이한 시간은 아직 계측하지 않았다.
