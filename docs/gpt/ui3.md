# 강호행 요청 32: 화면 틀 3: 싸움 화면 틀

단계 이름 `ui3` · 종류: 화면 틀 · 차례표: https://dltkdwhdhkd-design.github.io/gangho/docs/gpt/index.md

싸움 화면의 초상 틀, 체력·내력 막대, 초식 칸이다.

**이 단계에서 만들 것: 1개**

## 규칙

- **도트 그림(pixel art)**. 참고 그림 ref-ui.jpg(지금 게임 화면)의 사람 도트와 같은 굵기로. 그 화면에서 사람 키가 48도트쯤이다.
- 각진 도트로. 안티앨리어싱, 블러, 그라데이션, 반투명 없이. 번지고 마른 붓의 느낌은 색 단계 둘셋과 들쭉날쭉한 가장자리로 낸다.
- 배경은 완전한 **단색 초록(#00FF00)**. 그림 안에는 초록을 쓰지 않는다. 틀의 안쪽처럼 비워 둘 자리는 항목에 적혀 있다(비운 자리는 배경 초록 그대로 둔다).
- 칸은 크기가 모두 같고, 칸끼리 넉넉히 떼고, 그림이 칸 밖으로 나가지 않게. 칸 테두리, 번호, 서명을 넣지 않는다.
- **글자는 한 자도 넣지 않는다.** 한글과 한자는 게임이 제 글꼴로 얹는다.
- 느낌은 한지, 먹, 붓, 인장이다. 바탕 색: 한지색 #ece4d0, 먹색 #1c1a18, 금갈색 #a8782a, 진홍 #8e1838, 쪽빛 #22406a.
- 서양 판타지의 금속 테두리와 보석 장식, 일본풍 문양은 쓰지 않는다.

## 만들 것

### 1. `UI5.png` — 싸움 화면 틀 여섯 (2열 3행 6칸)

쓰는 곳: 싸움 화면의 초상 틀, 체력·내력 막대, 초식 칸. 지금은 검은 테두리 네모다.

```text
공통 규칙대로 도트 그림 한 장. 2열 3행 6칸으로 나누고 칸마다 하나씩 그려. 1) 초상 틀: 마름모꼴 먹색 틀(안은 비워 둔다. 비운 자리는 배경 초록 그대로), 금갈색 가는 테, 아래 귀에 작은 매듭 장식. 2) 긴 막대 틀: 가로가 세로의 10배인 막대, 왼쪽 끝은 붓이 시작한 듯 뭉툭하고 오른쪽 끝은 갈라진 먹색 붓자국 모양의 바탕. 3) 막대 채움 셋: 2의 막대 안에 들어갈 가는 띠 세 줄을 위아래로 나란히(위에서부터 진홍, 쪽빛, 금빛. 각각 밝은 줄 하나와 어두운 줄 하나의 두 단계). 4) 초식 칸(보통): 모서리를 둥글린 정사각형 먹색 판, 회갈색 가는 테. 5) 초식 칸(고른 것): 4와 같은 판에 금빛 테와 네 귀의 작은 불꽃 장식. 6) 적 이름 띠: 가로가 세로의 8배인 짙은 진홍 붓자국 띠와 그 아래 가는 막대 틀. 글자는 넣지 않는다.
```

## 스스로 확인

- 칸 수와 열·행이 항목대로인가
- 글자가 한 자도 없는가
- 바탕이 단색 초록인가. 그림 안에 초록이 없는가
- 창 틀은 네 귀에만 장식이 있고 변과 가운데가 고른가

## 넘기는 것

- 위의 파일 이름 그대로 넣은 압축 파일 하나: `gangho_ui3.zip`. 원본 크기의 PNG로(줄이거나 잘라 내지 않는다).
- 압축 파일을 만들 수 없으면 그림을 대화에 그대로 올리고, 그림마다 파일 이름을 한 줄씩 적는다.
