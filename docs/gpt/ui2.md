# 강호행 요청 27: 화면 틀 2: 화면 단추 그림, 머리 위 표식

단계 이름 `ui2` · 종류: 화면 틀 · 차례표: https://dltkdwhdhkd-design.github.io/gangho/docs/gpt/index.md

화면 구석의 단추와 사람·문 위에 뜨는 표식이다. 지금은 글자 단추와 화살표 하나뿐이다.

**이 단계에서 만들 것: 2개**

## 규칙

- **도트 그림(pixel art)**. 참고 그림 ref-ui.jpg(지금 게임 화면)의 사람 도트와 같은 굵기로. 그 화면에서 사람 키가 48도트쯤이다.
- 각진 도트로. 안티앨리어싱, 블러, 그라데이션, 반투명 없이. 번지고 마른 붓의 느낌은 색 단계 둘셋과 들쭉날쭉한 가장자리로 낸다.
- 배경은 완전한 **단색 초록(#00FF00)**. 그림 안에는 초록을 쓰지 않는다. 틀의 안쪽처럼 비워 둘 자리는 항목에 적혀 있다(비운 자리는 배경 초록 그대로 둔다).
- 칸은 크기가 모두 같고, 칸끼리 넉넉히 떼고, 그림이 칸 밖으로 나가지 않게. 칸 테두리, 번호, 서명을 넣지 않는다.
- **글자는 한 자도 넣지 않는다.** 한글과 한자는 게임이 제 글꼴로 얹는다.
- 느낌은 한지, 먹, 붓, 인장이다. 바탕 색: 한지색 #ece4d0, 먹색 #1c1a18, 금갈색 #a8782a, 진홍 #8e1838, 쪽빛 #22406a.
- 서양 판타지의 금속 테두리와 보석 장식, 일본풍 문양은 쓰지 않는다.

## 참고 그림 (모두 열어 볼 것)

- **지금 게임 화면 넷**(대화, 선택지, 메뉴, 싸움. 이 화면의 테두리와 단추를 바꾸는 그림이다): https://dltkdwhdhkd-design.github.io/gangho/docs/gpt/ref-ui.jpg
- 이미 있는 아이콘(도트의 급): https://dltkdwhdhkd-design.github.io/gangho/docs/gpt/ref-icons.png

주소를 못 열면 주인에게 그 파일을 올려 달라고 말한다.

## 만들 것

### 1. `UI3.png` — 화면 단추 그림 열둘 (4열 3행 12칸)

쓰는 곳: 화면 구석의 단추(지도, 짐, 무공 …). 지금은 글자만 있는 네모 단추다.

```text
공통 규칙대로 도트 그림 한 장. 정사각형이 아닌 4열 3행 12칸(가로 4 : 세로 3)으로 나누고, 칸마다 마름모꼴(정사각형을 45도 돌린 것) 먹색 판에 금갈색 가는 테를 두른 단추 하나를 칸의 4분의 3 크기로 그려. 판 안에는 흰 종이색(#ece4d0) 붓그림 한 가지씩: 1) 지도(반쯤 펼친 두루마리 지도), 2) 짐(묶은 보따리), 3) 무공(펼친 책과 붓), 4) 장비(칼과 갑옷), 5) 경맥(가부좌한 사람과 몸의 점), 6) 임무(인장이 찍힌 문서), 7) 동료(나란한 두 사람), 8) 문파(기와 전각), 9) 도감(끈으로 묶은 책 더미), 10) 설정(팔괘 무늬), 11) 저장(붉은 인장), 12) 닫기(붓으로 그은 엑스표). 열두 판은 크기와 테가 모두 같다. 글자는 넣지 않는다.
```

### 2. `UI4.png` — 머리 위 표식 열둘 (4열 3행 12칸)

쓰는 곳: 사람과 문 위에 뜨는 작은 표식(말 걸 수 있음, 임무, 가게 종류). 지금은 화살표 하나뿐이다.

```text
공통 규칙대로 도트 그림 한 장. 4열 3행 12칸으로 나누고, 칸마다 작은 표식 하나를 칸의 절반 크기로 그려(게임에서는 사람 머리만 한 크기로 뜬다). 짙은 남갈색 외곽선 1도트, 안은 밝게. 1) 말풍선(흰 종이색, 안에 점 셋), 2) 금빛 느낌표, 3) 금빛 물음표, 4) 위로 겹친 화살표 둘(문으로 들어감), 5) 엽전 꾸러미(가게), 6) 망치와 모루(대장간), 7) 술병과 잔(객잔), 8) 약탕기(의원), 9) 말 머리(역참과 표국), 10) 물고기(낚시터), 11) 엇갈린 칼 두 자루(싸움), 12) 뜬 눈(숨은 것). 글자는 넣지 않는다.
```

## 스스로 확인

- 칸 수와 열·행이 항목대로인가
- 글자가 한 자도 없는가
- 바탕이 단색 초록인가. 그림 안에 초록이 없는가
- 창 틀은 네 귀에만 장식이 있고 변과 가운데가 고른가

## 넘기는 것

- 위의 파일 이름 그대로 넣은 압축 파일 하나: `gangho_ui2.zip`. 원본 크기의 PNG로(줄이거나 잘라 내지 않는다).
- 압축 파일을 만들 수 없으면 그림을 대화에 그대로 올리고, 그림마다 파일 이름을 한 줄씩 적는다.
- 게임 코드는 고치지 않는다. 넣는 일은 Claude가 한다.
