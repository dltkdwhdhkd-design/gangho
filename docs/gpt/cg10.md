# 강호행 요청 91: 장면 그림 10: 형, 낙월, 국수 한 그릇, 달밤

단계 이름 `cg10` · 종류: 장면 그림 · 차례표: https://dltkdwhdhkd-design.github.io/gangho/docs/gpt/index.md

이야기의 큰 장면에 뜨는 그림이다. 게임에는 자리가 이미 있고, 그림이 없으면 색 바탕에 장면 제목만 뜬다.

**이 단계에서 만들 것: 4개**

## 규칙

- 도트가 아니라 **일러스트**다. 가로 16 : 세로 9(1536×864쯤). 참고 그림 ref-art.png와 같은 그림체: 한국 웹소설 표지풍의 깔끔한 2D 일러스트, 또렷한 선, 셀화 채색에 가벼운 명암(사진풍·3D풍 금지).
- 화면 아래쪽 4분의 1에는 대사 글이 얹힌다. 거기에는 얼굴이나 중요한 것을 두지 않고 조금 어둡게 둔다.
- 글자, 서명, 테두리, 말풍선을 넣지 않는다.
- 나오는 사람의 생김새는 항목에 적힌 일러스트 주소를 열어 보고 맞춘다(머리 모양과 색, 옷). 주인공은 스무 살 남자다: 검은 도포에 붉은 깃, 보라 허리띠, 길게 묶은 머리.
- 명나라풍과 한복풍을 섞은 가상의 고대 무협(기모노, 사무라이 금지).
- 싸움과 죽음이 나오는 장면도 피와 상처를 자세히 그리지 않는다. 실루엣, 표정, 빛으로 나타낸다.
