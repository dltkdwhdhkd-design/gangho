# 강호행 요청 30: 화산귀환 인물 얼굴 6: 당잔, 당패, 홍대광, 구칠, 종팔, 위립산

단계 이름 `face6` · 종류: 일러스트 · 차례표: https://dltkdwhdhkd-design.github.io/gangho/docs/gpt/index.md

『화산귀환』 인물(팬 캐릭터)은 걷는 도트는 있는데 대화 일러스트가 없어서, 말할 때 다른 사람의 얼굴이 나온다. 이미 있는 도트를 보고 그 사람의 일러스트를 그린다.

**이 단계에서 만들 것: 6개**

## 규칙

- 대화창에 뜨는 일러스트. 세로 1024×1536, 허벅지 위까지 보이는 한 사람. 몸은 오른쪽으로 살짝, 얼굴과 시선은 거의 정면. 머리와 손이 잘리지 않게.
- 참고 그림 ref-art.png와 같은 그림체: 한국 웹소설 표지풍의 깔끔한 2D 일러스트, 또렷한 선, 셀화 채색에 가벼운 명암(사진풍·3D풍 금지).
- 복장은 명나라풍과 한복풍을 섞은 가상의 고대 무협(기모노, 사무라이 금지).
- 배경은 투명하거나 무늬 없는 단색 회색. 글자, 서명, 테두리를 넣지 않는다.
- **도트 속 사람이 이 일러스트의 주인공이다.** 사람마다 적힌 도트 그림 주소를 열어 보고, 머리 모양과 색, 옷의 모양과 색, 장식, 무기를 도트와 똑같이 맞춘다.

## 참고 그림 (모두 열어 볼 것)

- 일러스트 그림체: https://dltkdwhdhkd-design.github.io/gangho/art-src/ref-art.png

주소를 못 열면 주인에게 그 파일을 올려 달라고 말한다.
