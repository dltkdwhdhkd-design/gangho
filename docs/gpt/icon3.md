# 강호행 요청 55: 아이콘 3: 초식 열여섯

단계 이름 `icon3` · 종류: 아이콘 · 차례표: https://dltkdwhdhkd-design.github.io/gangho/docs/gpt/index.md

싸움 화면의 초식 칸에 글자만 있다. 초식마다 그림을 넣는다.

**이 단계에서 만들 것: 1개**

## 규칙

- **도트 아이콘**. 참고 그림 ref-icons.png(이미 게임에 있는 아이콘)와 같은 급과 그림체로. 게임에서는 32×32도트로 쓰인다.
- 크게 그리되(한 칸 256픽셀쯤) 도트 한 점이 8픽셀쯤인 굵은 도트로. 각진 도트로(안티앨리어싱·블러·그라데이션·반투명 없이).
- 물건 하나를 칸 한가운데에. 짙은 남갈색 외곽선 1도트, 명암 3~4단, 빛은 왼쪽 위에서.
- 배경은 완전한 단색 초록(#00FF00). 그림 안에는 초록을 쓰지 않는다. 칸 테두리, 바닥 그림자, 글자, 번호를 넣지 않는다.
- 칸 순서는 왼쪽 위에서 오른쪽으로, 다음 줄로. 항목에 적힌 순서를 꼭 지킨다(게임이 칸 번호로 물건을 찾는다).
- 명나라풍 무협의 물건이다(일본도, 서양 갑옷 금지).

## 참고 그림 (모두 열어 볼 것)

- **이미 게임에 있는 아이콘**(이것과 같은 급과 그림체로): https://dltkdwhdhkd-design.github.io/gangho/docs/gpt/ref-icons.png
- 지금 게임 화면(아이콘이 쓰이는 자리): https://dltkdwhdhkd-design.github.io/gangho/docs/gpt/ref-ui.jpg

주소를 못 열면 주인에게 그 파일을 올려 달라고 말한다.

## 만들 것

### 1. `SK1.png` — 초식 아이콘 1 (16칸) (4열 4행 16칸)

쓰는 곳: 싸움 화면의 초식 칸과 무공 창. 지금은 초식 칸에 글자만 있다.

```text
공통 규칙대로 도트 아이콘 한 장. 4열 4행 16칸으로 나누고, 칸마다 무공 초식 하나를 나타내는 그림을 칸의 4분의 3 크기로 그려. 사람은 그리지 않고 그 초식의 움직임과 기운만 상징으로 그린다(검기의 궤적, 주먹과 충격파, 창끝과 소용돌이, 달과 칼빛 따위). 이름의 뜻과 문파의 색을 살려 열여섯 칸이 한눈에 서로 구별되게. 왼쪽 위부터 오른쪽으로, 다음 줄로: 1) 쟁반 던지기(점소이 잡기) 2) 비도술(강호 잡학) 3) 운기조식(강호 잡학) 4) 청운일섬(청운검법) 5) 유운삼검(청운검법) 6) 회풍검(청운검법) 7) 비연검기(청운검법) 8) 낙화유수(청운검법) 9) 창궁무애검(남궁세가) 10) 파산일도(파산도법) 11) 광풍난무(파산도법) 12) 혈선도(파산도법) 13) 오호단문도(하북팽가) 14) 일점돌(유룡창법) 15) 유룡천(유룡창법) 16) 횡소천군(유룡창법).
```

## 스스로 확인

- 칸 수와 순서가 항목대로인가
- 물건마다 서로 구별되는가. 크기가 고른가
- 바탕이 단색 초록이고 글자가 없는가

## 넘기는 것

- 위의 파일 이름 그대로 넣은 압축 파일 하나: `gangho_icon3.zip`. 원본 크기의 PNG로(줄이거나 잘라 내지 않는다).
- 압축 파일을 만들 수 없으면 그림을 대화에 그대로 올리고, 그림마다 파일 이름을 한 줄씩 적는다.
- 게임 코드는 고치지 않는다. 넣는 일은 Claude가 한다.
