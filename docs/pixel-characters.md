# 강호행 도트 요청서: 인물과 몬스터

필드와 전투에서 움직이는 작은 도트 인물, 몬스터, 동물을 ChatGPT에 맡기는 문서야. 번호는 C로 시작해. **대화할 때 나오는 큰 일러스트와는 별개야.** 일러스트 1~3순위를 이미 받았어도 이 도트는 새로 뽑아야 해.

## 먼저 읽을 것

- 걷기 프레임은 칸마다 키와 옷이 조금씩 달라질 수 있어. 그래서 3열×3행까지만 요구해. 더 많이 시키면 무너져.
- 큰 그림으로 받아서 내가 줄여 넣어. 게임 안에서는 지금보다 두 배 고운 32픽셀 칸으로 들어가.
- 인물은 첫 사람 그림을 보여 주면서 "이 화풍 그대로"라고 말하면 잘 맞아.

**순서**

1. 아래 "시험"부터 뽑아서 나한테 보내 줘. 이게 게임에 잘 들어가는지 먼저 확인해야 나머지가 헛일이 안 돼.
2. 시험을 통과하면 위에서부터 차례로 뽑아. 번호를 같이 적어 보내 주면 내가 번호로 찾아 넣을게.
3. 이 문서 하나는 대화방 하나에서 뽑아. 대화방이 바뀌면 화풍이 달라져. 다른 문서는 다른 대화방에서 해도 돼.
4. 그림이 마음에 안 들면 그 번호만 다시 뽑으면 돼. 파일 이름은 신경 쓰지 않아도 돼.

**대화방 첫 줄에 붙일 문장**

```
앞으로 그리는 그림은 전부 같은 게임에 들어가. 중국 무협 배경의 탑다운 RPG이고, 슈퍼패미컴 말기나 플레이스테이션 초기 2D 게임처럼 정갈한 도트 그림이야. 시점은 위에서 45도로 내려다본 3/4 시점. 외곽선은 어두운 색 1도트. 안티앨리어싱, 블러, 그라데이션, 반투명은 쓰지 마. 한 장에 32색 안쪽으로 그려. 글자, 워터마크, 테두리, 바닥 그림자는 넣지 마. 배경은 완전한 단색 마젠타(#FF00FF)로 칠하고, 마젠타는 그림 안에 쓰지 마. 일본 사무라이나 서양 판타지가 아니라 명나라 복식과 건축을 따라.
```

## 시험

**C1. 시험: 주인공 걷기** `T1`
```
정사각형 한 장을 3열 3행으로 나눠 같은 인물을 9번 그려. 1열은 앞모습, 2열은 뒷모습, 3열은 왼쪽을 보는 옆모습. 1행은 차렷, 2행은 왼발 내딛는 걷기, 3행은 오른발 내딛는 걷기. 머리가 조금 큰 2.5등신이고 아홉 칸 모두 키, 머리 크기, 옷, 색이 완전히 같아야 해. 칸끼리 넉넉히 떼고, 겹치지 마.
인물: 삼십 대 초반 남자 낭인. 검은 머리를 대충 묶었고, 낡은 검은 무명옷에 허리띠를 맸어. 표정은 무뚝뚝해.
```

## 인물 도트 (50명 × 2장)

인물마다 걷기 시트와 전투 시트를 한 장씩 뽑아. 같은 대화방에서 걷기 시트를 먼저 뽑고, 이어서 "방금 그 인물로" 전투 시트를 요청해. 앞의 12명이 주연이니 여기까지 먼저 해도 게임이 크게 달라져.

**걷기 시트 문장**

```
정사각형 한 장을 3열 3행으로 나눠 같은 인물을 9번 그려. 1열은 앞모습, 2열은 뒷모습, 3열은 왼쪽을 보는 옆모습. 1행은 차렷, 2행은 왼발 내딛는 걷기, 3행은 오른발 내딛는 걷기. 머리가 조금 큰 2.5등신이고 아홉 칸 모두 키, 머리 크기, 옷, 색이 완전히 같아야 해. 칸끼리 넉넉히 떼고, 겹치지 마.
```

**전투 시트 문장**

```

```
