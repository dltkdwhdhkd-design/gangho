# ChatGPT 요청서: 인물과 배경 (일검풍운결 급)

게임을 일검풍운결(逸劍風雲決, Wandering Sword)처럼 바꾸는 데 쓸 그림을 ChatGPT로 받는 문서야. 그대로 붙여 넣으면 돼. 게임을 어떻게 뜯어고치는지는 [hd2d-opus-prompt.md](hd2d-opus-prompt.md)에 있어.

받은 그림은 번호를 파일 이름에 적어서(예: `HC3_walk.png`, `FB3.png`) zip으로 묶어 보내 줘.

## 공통으로 지킬 것

- 1부(인물)와 2부(배경)는 **대화방을 따로** 써. 한 대화방 안에서는 그림체가 이어지고, 섞으면 섞여.
- 대화방을 열면 맨 먼저 그 부의 "첫 줄 문장"을 붙여. 일검풍운결 스크린샷을 한 장 같이 올리고 "이 게임의 도트 질감과 비율을 따라"라고 하면 훨씬 잘 맞아.
- 첫 그림이 마음에 들면 그다음부터는 그 그림을 다시 올리고 "이 그림체 그대로"라고 해.
- 한 번에 한 번호씩. 마음에 안 들면 그 번호만 다시 뽑아.
- **시험 번호(HC0)부터 받아서 나한테 보내 줘.** 이 그림으로 게임 쪽 크기와 칸을 맞춘 뒤에 나머지를 받아야 헛일이 안 돼.

# 1부. 인물 (일검풍운결 급 도트)

지금 인물 도트는 머리 큰 2.5등신에 키가 15점쯤이야. 일검풍운결은 3.5등신쯤에 키가 훨씬 크고, 옷 주름과 머리카락 결, 허리띠 매듭까지 찍혀 있어. 그 급으로 전부 새로 받아.

- 방향은 **정면, 뒷면, 옆면** 셋이야(쿼터뷰의 비스듬한 방향이 아니야). 오른쪽 옆모습은 내가 뒤집어 만들어.
- 인물마다 **세 장**: 걷기(앞뒤), 걷기(옆)와 서 있기, 전투.
- 칸이 많으면 인물이 흐트러져서 한 장에 여섯 칸까지만 시켜.

## 첫 줄 문장

```
앞으로 그리는 그림은 전부 같은 게임에 들어가. 명나라를 배경으로 한 무협 RPG이고, 일검풍운결(逸劍風雲決, Wandering Sword) 같은 HD-2D 게임이야. 인물은 그 게임과 같은 급의 세밀한 도트로 그려: 3.5등신, 머리가 조금 크지만 몸의 비례가 살아 있고, 한 인물의 키가 그림에서 300픽셀쯤 되게 크게. 얼굴에는 눈, 눈썹, 입이 작게 찍히고, 머리카락은 결 따라 3~4단 명암, 옷은 주름과 겹침이 보이게 4~5단 명암, 허리띠와 매듭과 소매 끝동 같은 작은 장식까지 찍어. 외곽선은 짙은 갈색이나 짙은 남색 1도트. 빛은 왼쪽 위에서. 도트의 각이 살아 있어야 해: 안티앨리어싱, 블러, 그라데이션, 반투명은 쓰지 마. 글자, 워터마크, 테두리, 바닥 그림자는 넣지 마. 배경은 완전한 단색 마젠타(#FF00FF)로 칠하고 그림 안에는 마젠타를 쓰지 마. 일본풍이나 서양 판타지가 아니라 명나라 복식을 따라.
```

## 걷기 시트 문장 (앞뒤)

```
정사각형 한 장을 2열 3행으로 나눠 같은 인물을 6번 그려. 1열은 정면(카메라를 똑바로 봄), 2열은 뒷모습(등과 뒤통수). 1행은 차렷, 2행은 왼발을 내딛는 걸음, 3행은 오른발을 내딛는 걸음. 걸을 때 팔이 반대로 흔들리고 옷자락과 머리카락이 살짝 따라 움직여. 여섯 칸 모두 키, 머리 크기, 옷, 색이 완전히 같아야 해. 칸끼리 넉넉히 떼고 겹치지 마.
```

## 걷기 시트 문장 (옆)

```
방금 그 인물을 정사각형 한 장에 2열 3행으로 6번 그려. 여섯 칸 모두 왼쪽을 보는 옆모습이야. 1행은 차렷과 숨 쉬는 자세(어깨가 살짝 올라감), 2행은 왼발 내딛기와 두 발이 모이는 중간 걸음, 3행은 오른발 내딛기와 두 발이 모이는 중간 걸음. 앞뒤 걷기 그림과 같은 인물이고 키, 머리 크기, 색이 같아야 해.
```

## 전투 시트 문장

```
방금 그 인물을 정사각형 한 장에 2열 3행으로 6번 그려. 여섯 칸 모두 왼쪽을 보는 옆모습이야. 1행은 무술 준비 자세와 몸을 크게 틀어 내지르는 공격 자세, 2행은 뛰어오르는 자세와 양팔을 모아 막는 자세, 3행은 맞아서 몸이 젖혀진 자세와 한쪽 무릎을 꿇고 쓰러진 자세. 무기는 들지 마. 무기는 게임이 손에 붙여. 걷기 그림과 같은 인물이고 키, 머리 크기, 색이 같아야 해.
```

## 동물과 몬스터

인물과 같은 급의 도트로, 정사각형 한 장을 2열 2행으로 나눠 받아. 1열은 정면, 2열은 왼쪽을 보는 옆모습, 1행과 2행은 움직이는 두 동작이야. 아래 이름만 바꿔 넣으면 돼.

```
방금까지와 같은 급의 세밀한 도트로 [이름]을 그려. 정사각형 한 장을 2열 2행으로 나눠 같은 것을 4번. 1열은 정면, 2열은 왼쪽을 보는 옆모습. 1행과 2행은 움직이는 두 동작. 크기와 색이 같아야 해.
```

- 동물: HA1 닭, HA2 누렁이 개, HA3 누런 소, HA4 갈색 말, HA5 고양이, HA6 산토끼, HA7 꿩, HA8 노루, HA9 멧돼지 새끼, HA10 오소리, HA11 서역 낙타
- 몬스터: HM1 멧돼지, HM2 독사, HM3 큰 구렁이, HM4 너구리, HM5 대나무 귀신, HM6 푸른 원혼, HM7 흰 망자, HM8 사막 도마뱀, HM9 해골 강시

# 2부. 배경

배경 요청서는 일검풍운결 급으로 다시 써서 [hd2d-requests.md](hd2d-requests.md)로 옮겼어(번호 HB). 인물도 정면 시점 3.5등신 도트로 새로 받는 요청서(번호 HC)가 거기 있어. 이 문서 1부는 쿼터뷰 모드용 걷기 그림이야.

## 5순위: 방 안

일검풍운결의 방은 뒷벽이 서 있고 앞벽이 없는 무대 모양이야. 방마다 한 장씩, 그림 전체를 채워 받아(마젠타 배경 아님). 사람은 넣지 마.

**FB14~FB19. 방 여섯 가지**
```
게임의 방 안 배경을 한 장 그려. 가로로 긴 그림(16:9). 정면에서 30도쯤 내려다본 무대 모양: 뒷벽이 화면 위쪽에 서 있고 양옆 벽이 조금 보이고 앞벽은 없어. 바닥이 화면의 아래 3분의 2를 차지하고, 가운데는 사람이 걸어 다니게 비워 둬. 가구는 뒷벽과 양옆 벽에 붙여. 문은 아래쪽 가운데에 문턱만 보이게. 사람은 넣지 마. 창으로 햇빛이 비스듬히 들어와 바닥에 떨어져.
방: [아래에서 하나]
```
- FB14 객잔 일층: 뒷벽에 술독 선반과 계산대, 네모 탁자 넷, 한쪽에 이층 계단
- FB15 살림집: 구들과 이불, 작은 탁자, 부뚜막, 물독
- FB16 약방: 뒷벽 가득 약장, 계산대, 침상 하나, 약초 말리는 채반
