# 그림 요청서 (일검풍운결 급)

> 지금 받을 그림은 사람(일러스트·도트)은 `docs/gemini-now.md`, 건물·땅·소품은 `docs/chatgpt-now.md`에 모아 둔다. 이 문서는 예전 기록이다.

둘로 나눴어. 각각 통째로 ChatGPT에 주면 돼. 대화방은 따로 써.

- [인물](chatgpt-characters.md): 3.5등신 세밀 도트, 50명 × 3장과 동물·몬스터. 번호 HC.
- [배경 2판](chatgpt-backgrounds.md): 땅 HG, 지붕 HR, 건물 벽 HW, 문·담 HK, 나무 HT, 살림 HP, 먼 배경 HF, 방 HI. **HG1 → HR1 → HW0(시험 집)부터.**

배경 대화방에는 일검풍운결 낮 화면 한 장을 먼저 올려. 받은 그림은 번호를 파일 이름에 적어 줘.
