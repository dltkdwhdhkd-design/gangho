# 1부. 기획

## 지금 무엇이 문제인가

- 화산 초식이 "꽃 모양 덩어리가 날아가는" 그림이다. 화산귀환의 화산 검법은 꽃이 날아가는 게 아니라 **검이 지나간 자리에 매화가 피어난다.**
- 화산 초식 여섯 개(매화삼롱, 낙영검, 자하검기, 이십사수매화검, 매화만개, 이십사수매화검법)가 색만 분홍이고 생김새는 다른 문파와 같은 틀을 쓴다.

## 화산 연출의 다섯 규칙

1. **매화는 핀다.** 검끝과 검기가 지나간 자리에서 봉오리 → 반쯤 핌 → 만개 → 흩날림 순서로 피고 진다. 꽃 모양 장풍은 쓰지 않는다.
2. **검기는 매화 가지다.** 붉은 검광이 곧은 선이 아니라 가지처럼 갈라져 뻗고, 마디마다 꽃이 맺힌다.
3. **꽃잎은 흩날린다.** 직선으로 날지 않는다. 좌우로 흔들리고 뒤집히며 천천히 떨어지고, 싸움이 끝난 뒤에도 잠깐 남는다(암향, 남는 향기).
4. **늦게 피고 한꺼번에 터진다.** 검이 먼저 번쩍 지나가고 0.1~0.2초 고요한 뒤에 꽃이 "팡" 피며 피해가 들어간다. 꽃이 필 때 화면이 아주 잠깐 멈춘다(타격 정지).
5. **색은 셋.** 진홍 매화(#C8284A), 연분홍 꽃잎(#FF9FBD), 흰 꽃잎(#FFF0F5)과 노란 꽃술 점. 자하신공·자하검기만 보랏빛 노을(#8A5AD8, #C9A8FF)을 두른다.

- 칼빛: 짧은 쇳소리. 꽃이 필 때: 낮은 "팡"과 바람 소리. 만개: 큰 바람 소리 뒤 고요.
- 타격 정지: 보통 0.05초, 만개 0.12초, 매화만개 0.3초.
- 꽃잎이 흩날리는 동안은 소리 없이 둔다(웹툰의 정적).

# 2부. ChatGPT 그림 요청

## 공통 규칙 (모든 항목)

- **도트 그림(pixel art)**. 참고 그림 `ref-fx.png`의 사람 도트와 같은 굵기. 사람 키는 그 그림에서 48도트쯤이다.
- 각진 도트로. 안티앨리어싱, 블러, 그라데이션, 반투명, 빛번짐 없이. 빛나는 느낌은 **밝은 색 단계**(진홍 → 분홍 → 흰색)로 낸다.
- 배경은 완전한 **단색 초록(#00FF00)**. 그림 안에는 초록을 쓰지 않는다.
- 칸은 크기가 모두 같게, 칸끼리 넉넉히 떼고, 그림이 칸 밖으로 나가지 않게. 글자·번호·테두리 없이.
- 한 장 안의 칸은 **왼쪽 위에서 오른쪽으로, 다음 줄로** 시간 순서다.
- 색: 진홍 #C8284A, 짙은 진홍 #8E1838, 분홍 #FF9FBD, 연분홍 #FFC4D6, 흰 꽃잎 #FFF0F5, 꽃술 노랑 #FFE36A. 자하는 보라 #8A5AD8, 연보라 #C9A8FF, 짙은 보라 #4A2C7A.
- 일본 벚꽃이 아니라 **매화**다. 꽃잎 다섯 장이 둥글고, 가운데 꽃술이 짧게 많다.

```text
공통 규칙대로 도트 그림 한 장. 가로가 세로의 두 배인 그림을 4열 2행 8칸으로 나눠(칸도 가로로 긴 2:1). 오른쪽으로 날아가는 큰 초승달 검기. 안쪽은 흰색과 연분홍, 바깥은 보랏빛 노을이 두르고, 뒤쪽 가장자리에서 매화 꽃잎이 떨어져 나간다. 1~4 날아가는 동안의 되풀이 동작(노을과 꽃잎 위치만 조금씩 바뀜), 5~8 검기가 부서지며 꽃잎과 보라 안개로 흩어져 사라짐. 배경은 단색 초록(#00FF00).
```

## H10. 매화만개 이름띠 그림 `cut_plum.png` (가로 3:1, 일러스트)

이것만 도트가 아니라 일러스트다. 절초 이름이 뜰 때 띠 뒤에 깔린다.

```text
가로가 세로의 세 배인 그림 한 장. 한국 웹툰풍 무협 일러스트(도트 아님), 또렷한 선과 셀화 채색. 검은 밤하늘 바탕에, 오른쪽에서 왼쪽으로 뻗은 붉은 빛의 매화 가지와 수십 송이의 만개한 매화, 공중을 가득 채운 꽃잎. 가운데에 검을 비스듬히 든 검객의 뒷모습 실루엣(얼굴은 보이지 않게, 검은 무복, 묶은 머리). 가운데 위아래는 글자가 얹힐 자리라 조금 어둡게. 진홍·분홍·흰색만, 다른 색 없이. 글자·서명 없이.
```

---

받은 뒤 Claude가 하는 일: 칸을 잘라 효과 시트로 만들고(초록 배경을 지워 테두리를 다듬는다), 1부의 박자대로 초식마다 붙인다. 지금 코드로 그리는 꽃잎은 H1이 오면 H1로 바뀐다.
