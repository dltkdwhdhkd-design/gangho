알아 둘 것
- 원본에서 도트 한 점 크기: 땅과 지붕 무늬는 9픽셀쯤, 벽은 4픽셀쯤, 인물은 3.5픽셀쯤. 화면에서 도트 한 점 크기가 서로 같아지게 축척을 잡는다.
- 무늬를 이어 붙이면 이음매가 보이는 칸이 있다(판석 돌마당, 막돌 바닥, 주황 기와, 눈 기와). 넣을 때 돌이나 기와 줄이 온전히 떨어지는 자리에서 잘라 맞춘다.
- 흙길은 수레 자국이 세로로 나 있다. 가로 길에는 돌려 쓴다. 눈 발자국처럼 눈에 띄는 무늬는 되풀이가 드러나니 섞어 쓰거나 지운다.
