# Higgsfield로 받은 그림

받은 원본은 Higgsfield 저장소에 있고, 잘라 넣는 일은 `tools/hf_cut.py`가 한다(배경을 지우고 붙은 덩어리마다 잘라 도트 굵기 48/15로 줄인다).

| 번호 | 내용 | 모델 | 상태 |
|---|---|---|---|
| HT1 | 나무 여덟(소나무, 녹나무, 매화, 버드나무, 대나무, 단풍, 떨기나무, 죽은 나무), 4열 2행 | gpt_image_2_6 medium 2k, 참고 HP2 + 일검풍운결 낮 화면 | 받음, 잘라 둠(t_*) |
| HP3 | 살림 소품 열둘(긴 의자, 찻상, 물독, 장작 헛간, 빨래 장대, 화분, 대울타리, 돌담, 고추 말리는 시렁, 마늘·옥수수 걸이, 사다리와 짚단, 닭장) | 같음, 참고 HP2 | 받음, 잘라 둠(p_*) |
| HP4 | 땅 덮개 열둘(키 큰 풀, 고사리, 노란 꽃, 흰·보라 꽃, 이끼 바위, 돌무더기, 쓰러진 통나무, 버섯 그루터기, 갈대, 연잎, 작은 덤불, 덩굴) | 같음, 참고 HP2 + 일검풍운결 낮 화면 | 받음, 잘라 둠(g_*) |
| HW2 | 큰 건물 벽(법당, 문파 회관, 부잣집; 1행 앞벽, 2행 옆벽), 참고 HW1 | gpt_image_2_6 medium 2k | 받음 |
| HN2a/b | 아낙 걷기(a 앞·뒤, b 옆), 참고 HC1a/b | 같음 | a 받음, b 요청함 |
| HN3a/b | 노인(지팡이) 걷기 | 같음 | a 받음, b 요청함 |
| HN4a/b | 노파(등짐) 걷기 | 같음 | a 받음, b 요청함 |
| HN1a | 마을 사내 걷기 | 무료 줄 | 30분 넘게 기다리는 중 |

받은 원본은 아직 이 저장소로 못 옮겼다: 작업 공간에서 Higgsfield 파일 주소(d8j0ntlcm91z4.cloudfront.net)에 닿지 않는다. 주소를 허용하면 내려받아 `tools/hf_cut.py`로 자른다.

요청 원문은 `docs/higgsfield-requests.md`.
